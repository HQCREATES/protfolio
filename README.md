# HQ Creative — Portfolio

Responsive dark portfolio with purple gradients, CSS artwork, animated sections, and project filtering. Built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive visual design and animations
- `script.js` — navigation, scroll reveals, filters, and email form

## Preview locally
Open `index.html` in a browser. Google Fonts require an internet connection; the rest runs without a build step.

## Personalize
- Update the contact email in `index.html` and `script.js`.
- Replace Instagram, Behance, and LinkedIn links with your real profiles.
- Replace the sample CSS project artwork and descriptions with your actual work. The project cards are concept placeholders, not claimed client projects.
- The contact form uses a `mailto:` link and opens the visitor's email app; it does not store submissions on a server.

## GitHub Pages
This repository includes a Pages workflow. Open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if GitHub Pages is not already enabled. The workflow publishes the repository root after each push to `main`.
